# Semester Notes

Personal scaffold for organizing my own classwork by semester and subject.

## Structure

- `N SEMESTER/` — one folder per semester
  - `Subject Name/` — one folder per class

The subject folders are pre-populated from a full undergrad CS/data-science curriculum as a starting template. Rename, delete, or add folders each term to match your actual course list — each one starts with a placeholder `README.md` to replace with real notes, assignments, and resources.

This repo previously tracked a fork of someone else's public study-notes project; that history has been dropped in favor of a clean scaffold for original coursework going forward.
